# Mott Research

A clean Next.js rebuild of [mottresearch.com](https://mottresearch.com), preserving the company’s existing design, content, imagery, page structure, legacy `.php` URLs, and page-level SEO metadata while adding responsive layouts.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

The project is ready to import into Vercel with the default Next.js settings.
